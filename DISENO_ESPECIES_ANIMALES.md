### Sistema de Spawn por Bioma

#### **Mecánica:**
1. **Densidad Base por Zona**
   - Ciudad: 0.5 animales/km²
   - Pueblo: 2 animales/km²
   - Campo: 5 animales/km²
   - Bosque: 8 animales/km²
   - Montaña: 3 animales/km²
   - Agua: 10 animales/km²

2. **Tabla de Spawn:** Cada zona tiene % de aparición de cada especie

3. **Regeneración:** Sistema de respawn cada X días (simulación)

## 📊 SISTEMA DE IMPLEMENTACIÓN

### Tabla: `fauna_zonas`

```sql
CREATE TABLE fauna_zonas (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    zona_id INTEGER NOT NULL,  -- FK a pueblos_ciudades
    especie_animal VARCHAR(100) NOT NULL,
    densidad_base INTEGER DEFAULT 10,  -- Cantidad base
    rareza FLOAT DEFAULT 1.0,  -- Multiplicador rareza (0.01-1.0)
    es_mitologico BOOLEAN DEFAULT 0,
    agresividad INTEGER DEFAULT 0,  -- 0-100
    estado VARCHAR(50) DEFAULT 'salvaje',  -- 'salvaje', 'domestico', 'feral'
    FOREIGN KEY (zona_id) REFERENCES pueblos_ciudades(id)
);
```

### Tabla: `especies_animales`

```sql
CREATE TABLE especies_animales (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre_comun VARCHAR(100) NOT NULL,
    nombre_nahuatl VARCHAR(100),
    categoria VARCHAR(50),  -- 'domestico', 'salvaje', 'mitologico'
    peligrosidad VARCHAR(20),  -- 'ninguna', 'baja', 'media', 'alta', 'extrema', 'legendaria'
    valor_mercado INTEGER DEFAULT 0,
    descripcion TEXT,
    habilidades_especiales TEXT,  -- JSON
    biomas_preferidos TEXT  -- JSON: ['bosque', 'agua', etc]
);
```

### Tabla: `animales_individuales`

```sql
-- Solo para animales importantes (mitológicos, monturas, mascotas de NPCs)
CREATE TABLE animales_individuales (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    especie_id INTEGER NOT NULL,
    nombre VARCHAR(100),  -- Solo si tienen nombre (mascotas)
    dueño_id INTEGER,  -- NULL si salvaje
    zona_actual_id INTEGER,
    año_nacimiento INTEGER,
    año_muerte INTEGER,
    es_montura BOOLEAN DEFAULT 0,
    es_mascota BOOLEAN DEFAULT 0,
    nivel_entrenamiento INTEGER DEFAULT 0,
    FOREIGN KEY (especie_id) REFERENCES especies_animales(id),
    FOREIGN KEY (dueño_id) REFERENCES personas(id)
);
```
